# make-comment

**유튜브 댓글 자동 답글 — 내가 예전에 단 답글을 AI가 학습해서, 내 말투로 새 댓글에 답해줍니다.**

- 답글 문장은 Claude 구독(claude 명령)으로 생성 — **별도 AI API 키가 필요 없습니다**
- **미리보기(dry-run)가 기본**: 답글안을 먼저 보여주고, 여러분이 "게시해"라고 해야만 실제로 달립니다
- 실행은 항상 1회 단발 — "답글 달아줘" 한 번 = 확인 한 번

---

## 어떻게 작동하나요?

```
"답글 달아줘"
  ↓
1. 내 채널의 새 댓글을 확인 (이미 답한 댓글·내가 쓴 댓글은 자동 제외)
2. 내 과거 답글 20개를 학습한 AI가 내 말투로 답글안 작성
   (스팸·의미 없는 댓글은 알아서 건너뜀)
3. 답글안을 표로 보여주고 → "이대로 게시할까요?"
4. 승인하면 게시 → 결과 보고
```

---

## 사전 과제 (수업 전에 꼭!)

이 도구는 여러분의 유튜브 채널에 답글을 달기 위해 **구글의 허락(OAuth)**이 필요합니다.
구글에서 `client_secret.json`이라는 열쇠 파일을 발급받아야 하는데, 15분 정도 걸립니다.

**→ [docs/google-oauth.md](docs/google-oauth.md) 가이드를 따라 발급받아 이 폴더에 넣어주세요.**

(무료입니다. 스크린샷이 포함된 판은 수업 자료 Drive 폴더에도 있습니다.)

그 외 준비물:

- **Python 3.10+** (설치 시 Windows는 "Add python.exe to PATH" 체크!)
- **Claude Code** (이미 설치되어 있다는 전제)
- 유튜브 채널 (과거에 단 답글이 몇 개 있으면 말투 학습이 잘 됩니다)

## 시작하기

VS Code에서 압축을 푼 `make-comment` **폴더 자체**를 열고, Claude Code에서 순서대로:

| 순서 | 말하면 되는 것 | 하는 일 |
|------|----------------|---------|
| 1 | `"세팅해줘"` | 가상환경·의존성·설정 파일 준비 |
| 2 | `"인증해줘"` | 브라우저에서 구글 로그인 → 채널 ID까지 자동 설정 |
| 3 | `"댓글 확인해줘"` | 새 댓글 + 답글안 미리보기 (게시 안 함) |
| 4 | `"답글 달아줘"` | 미리보기 → 확인 → 실제 게시 |

문제가 생기면 언제든: `"점검해줘"` — ✅❌ 진단 리포트가 나옵니다.

---

## 내 채널답게 만들기

- **`config/channel.md`** — 채널 소개·말투·금지 규칙. 이 파일이 답글의 성격을 결정합니다.
  Claude에게 "말투 바꿔줘"라고 말해도 됩니다.
- **말투 학습**: 첫 실행 때 내 과거 답글(최대 20개)을 자동 수집해 `tone_examples.json`에 저장합니다.
  최근 답글 스타일을 다시 배우게 하려면 "말투 다시 배워줘".

## 프로젝트 구조

```
make-comment/
├── CLAUDE.md               # Claude 지시사항 (자동으로 읽음)
├── README.md               # 이 파일
├── VERSION / CHANGELOG.md  # 버전 정보
├── requirements.txt        # Python 의존성 (3개)
├── .env.example            # 설정 견본 (.env로 복사해 사용 — 세팅해줘가 자동으로)
├── .claude/skills/
│   ├── setup/SKILL.md      #   "세팅해줘" / "인증해줘"
│   ├── comment/SKILL.md    #   "댓글 확인해줘" / "답글 달아줘"
│   └── doctor/SKILL.md     #   "점검해줘"
├── scripts/
│   ├── main.py             #   1회 실행 엔진 (dry-run 기본)
│   ├── youtube_api.py      #   유튜브 API (댓글 조회·게시·말투 수집)
│   ├── llm.py              #   claude 명령으로 답글 생성
│   ├── auth_setup.py       #   구글 인증
│   └── status.ps1          #   (Windows·상시 실행용) 상태 확인
├── prompts/auto-reply.md   # 답글 원칙 (감정 공감·스팸 제외·안전 규칙)
├── config/channel.md       # 내 채널 프로필 ← 여기만 고치면 됩니다
└── docs/
    ├── google-oauth.md     # 구글 OAuth 발급 가이드 (사전 과제)
    └── always-on.md        # 심화: 컴퓨터가 알아서 주기적으로 돌게 하기
```

실행하면 생기는 파일 (전부 내 컴퓨터에만 저장):

| 파일 | 내용 |
|------|------|
| `token.json` | 구글 인증 토큰 — **절대 남에게 보내지 마세요** |
| `tone_examples.json` | 내 과거 답글 (말투 학습용) |
| `processed.json` | 이미 처리한 댓글 기록 (중복 답글 방지) |
| `logs/bot.log` | 실행 기록 |

## 안전장치

- **dry-run 기본**: 미리보기 없이 게시되는 일이 없습니다
- **중복 방지**: 답한 댓글은 기록되어 두 번 달리지 않습니다
- **본인 댓글 제외**: 내가 단 고정 댓글 등에는 답글을 달지 않습니다
- **스팸 무시**: 광고·욕설·의미 없는 댓글은 답글 없이 건너뜁니다
- **API 절약**: 댓글 수가 안 변한 영상은 건너뛰어 하루 무료 한도(10,000)로 충분합니다

## 트러블슈팅

문제가 생기면 우선 **"점검해줘"** — 나온 결과를 캡처해서 조교에게 보내는 것이 가장 빠릅니다.
(단, `client_secret.json`·`token.json` 파일 내용은 절대 캡처하지 마세요!)

| 증상 | 해결 |
|------|------|
| "client_secret.json이 없습니다" | 사전 과제 — `docs/google-oauth.md` 가이드로 발급 |
| 인증 중 "액세스 차단됨" / 403 | 구글 클라우드에서 **테스트 사용자**에 본인 이메일 추가 (가이드 5단계) |
| "Google에서 확인하지 않은 앱" 경고 | 정상입니다 — "고급" → "이동" 클릭 (본인이 만든 앱) |
| 답글이 안 달리고 quotaExceeded | 오늘 무료 한도 소진 — 내일 다시 (한국시간 오후 4~5시경 리셋) |
| 답글 말투가 마음에 안 듦 | `config/channel.md` 수정 또는 "말투 다시 배워줘" |
| 오래 걸림 | 정상 — 답글 생성에 영상당 몇십 초 걸릴 수 있습니다 |
