# Comment Skill

새 댓글을 확인하고, 내 과거 답글 말투를 학습한 AI가 답글안을 만들어 게시한다.

## 절대 규칙

1. **사용자의 명시적 승인 없이 `--no-dry-run`을 절대 실행하지 않는다.**
   "답글 달아줘"라는 말 자체는 승인이 아니다 — 반드시 dry-run 결과를 먼저 보여주고 물어본다.
2. `client_secret.json`·`token.json`·`.env` 내용은 읽거나 출력하지 않는다.

## 모드 판별

| 사용자가 말하면 | 모드 |
|----------------|------|
| "댓글 확인해줘", "새 댓글 봐줘" | **미리보기** — STEP 1~2만 하고 종료 (게시 안 함) |
| "답글 달아줘", "댓글 달아줘" | **게시** — STEP 1~4 전체 |
| "말투 다시 배워줘", "말투 새로 수집해줘" | **말투 재수집** — 아래 별도 절차 |

## STEP 1. 미리보기 실행 (dry-run)

```
{VENV_PYTHON} scripts/main.py --dry-run
```

- 준비가 안 된 상태면 스크립트가 문제·해결법을 한글로 출력하고 멈춘다 → 그 안내를 그대로 전달하고,
  해결이 "세팅해줘"/"인증해줘"로 가능하면 해당 스킬로 이어간다
- 최초 실행이면 말투 예시 수집(내 과거 답글 → few-shot)이 자동으로 먼저 돈다 — "말투를 배우는 중"이라고 설명

## STEP 2. 결과 보여주기

dry-run 출력의 "미리보기 결과" 블록을 표로 정리해 보여준다:

| # | 영상 | 댓글 (작성자) | 답글안 |
|---|------|--------------|--------|

- 건너뛴 것(스팸·무의미 댓글)의 개수도 알려준다
- 새 댓글이 0개면: "새 댓글이 없어요. 다음에 다시 확인해보세요." 하고 종료
- **미리보기 모드면 여기서 종료**: "실제로 달고 싶으시면 '답글 달아줘'라고 말해주세요."

## STEP 3. 사용자 확인 → 실제 게시

"이대로 게시할까요?"라고 묻는다. 특정 답글이 마음에 안 든다고 하면:
- `config/channel.md`의 말투·금지 규칙을 조정해주고 STEP 1부터 다시

승인하면 실행:

```
{VENV_PYTHON} scripts/main.py --no-dry-run
```

> 참고: 실제 게시 시 답글이 새로 생성되므로 미리보기와 문구가 조금 다를 수 있다. 원칙과 말투는 동일하다.

## STEP 4. 결과 보고

- 게시 성공/실패/건너뜀 개수
- 게시된 답글은 유튜브에서 바로 확인 가능함을 안내
- 처리 기록은 `processed.json`에 저장되어 같은 댓글에 두 번 달리지 않음을 안내
- 마무리: "새 댓글이 또 쌓이면 '답글 달아줘'라고 말해주세요. 매번 확인 없이 자동으로 돌리고 싶으시면 `docs/always-on.md`를 참고하세요."

## 말투 재수집

```
{VENV_PYTHON} scripts/main.py --dry-run --refresh-tone
```

과거 답글을 다시 수집해 `tone_examples.json`을 갱신한다 (최근 영상 10개에서 최대 20개).
수집 후 몇 개를 배웠는지 보고한다.

## 에러 대응

| 증상 | 대응 |
|------|------|
| "client_secret.json이 없습니다" | `docs/google-oauth.md` 안내 (수업 사전 과제) |
| "인증을 하지 않았습니다" | "인증해줘" 실행 (setup 스킬 STEP 5부터) |
| "YOUTUBE_CHANNEL_ID가 비어 있습니다" | "인증해줘" 하면 자동 기입됨 |
| 403 quotaExceeded | 오늘 API 사용량 소진 — 내일 다시 (한국시간 오후 4~5시경 리셋) |
| 403 forbidden (댓글) | 해당 영상이 댓글 제한 상태일 수 있음 — 다른 댓글은 정상 처리됨 |
| claude 호출 실패/타임아웃 | 네트워크 확인 후 재시도. 반복되면 "점검해줘" |
| token 관련 invalid_grant | token.json 삭제 후 "인증해줘" 재실행 |
