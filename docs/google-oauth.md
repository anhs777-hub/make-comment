# 구글 OAuth 발급 가이드 (사전 과제)

> **목표**: 구글에서 `client_secret.json` 파일 하나를 발급받아 `make-comment` 폴더에 넣는 것.
> **소요 시간**: 약 15분 · **비용**: 무료
> 스크린샷이 포함된 판은 수업 자료 Drive 폴더에 있습니다. 이 문서는 글로 된 안내입니다.

## 이게 왜 필요한가요?

이 도구가 **여러분의 유튜브 채널에 답글을 다는 것을 구글에게 허락받는 열쇠**입니다.
열쇠는 여러분 컴퓨터에만 저장되고, 다른 곳으로 전송되지 않습니다.

준비물: 유튜브 채널을 운영하는 **구글 계정** (그 계정으로 진행하세요!)

---

## 1단계. Google Cloud Console 접속

1. 인터넷 주소창에 입력: **console.cloud.google.com**
2. 유튜브 채널을 운영하는 구글 계정으로 로그인
3. 처음 방문이면 약관 동의 화면이 나옵니다 → 체크하고 **"동의 및 계속하기"**

## 2단계. 새 프로젝트 만들기

1. 화면 **왼쪽 위**, Google Cloud 로고 옆의 **프로젝트 선택 버튼**을 클릭
   (처음이면 "프로젝트 선택"이라고 적혀 있습니다)
2. 뜨는 창의 오른쪽 위 **"새 프로젝트"** 클릭
3. 프로젝트 이름: **make-comment** 라고 입력 (아무 이름이나 괜찮습니다)
4. **"만들기"** 클릭 → 잠시 기다리면 완성
5. 다시 왼쪽 위 프로젝트 선택 버튼을 눌러 방금 만든 **make-comment**를 선택
   (이후 모든 작업은 이 프로젝트 안에서 합니다)

## 3단계. YouTube Data API v3 켜기

1. 화면 위쪽 **검색창**에 입력: **YouTube Data API v3**
2. 검색 결과에서 **"YouTube Data API v3"** 클릭
3. 파란색 **"사용"** (또는 "사용 설정") 버튼 클릭
   - 이미 "API 사용 설정됨"이라고 나오면 그대로 통과

## 4단계. OAuth 동의 화면 만들기

1. 왼쪽 위 **메뉴(≡ 삼선 버튼)** → **"API 및 서비스"** → **"OAuth 동의 화면"** 클릭
   - 최근 화면에서는 **"Google 인증 플랫폼"**이라는 이름으로 나올 수 있습니다. 같은 곳입니다.
2. 처음이면 **"시작하기"** 버튼이 보입니다 → 클릭하고 순서대로 입력:
   - **앱 이름**: make-comment
   - **사용자 지원 이메일**: 본인 이메일 선택
   - **대상**(Audience): **"외부"(External)** 선택
   - **연락처 정보**: 본인 이메일 입력
   - 약관 동의 체크 → **"만들기"**

## 5단계. 테스트 사용자 추가 (⭐ 가장 많이 빠뜨리는 단계!)

이걸 빠뜨리면 나중에 인증할 때 **"액세스 차단됨"(403)** 오류가 납니다.

1. OAuth 동의 화면(Google 인증 플랫폼)에서 **"대상"**(Audience) 메뉴 클릭
2. 아래로 내려 **"테스트 사용자"** 항목에서 **"+ Add users"** 클릭
3. **본인 구글 이메일**(유튜브 채널 계정)을 입력 → **"저장"**

## 6단계. 클라이언트(열쇠) 만들기

1. 왼쪽 메뉴에서 **"클라이언트"** 클릭
   - 예전 화면에서는: "API 및 서비스" → "사용자 인증 정보" → 위쪽 **"+ 사용자 인증 정보 만들기"** → **"OAuth 클라이언트 ID"**
2. **"+ 클라이언트 만들기"** (또는 "OAuth 클라이언트 ID 만들기") 클릭
3. **애플리케이션 유형**: **"데스크톱 앱"** 선택
4. 이름: 그대로 두고 → **"만들기"**

## 7단계. JSON 파일 다운로드 → 폴더에 넣기

1. 만들기가 끝나면 뜨는 창(또는 클라이언트 목록의 다운로드 아이콘 ⬇)에서 **"JSON 다운로드"** 클릭
2. `client_secret_숫자들.json` 같은 긴 이름의 파일이 **다운로드 폴더**에 저장됩니다
3. 이 파일의 이름을 **`client_secret.json`** 으로 바꿔주세요
   - 파일을 클릭 → 키보드 F2(Mac은 Enter) → 이름 수정
   - 주의: `client_secret (1).json`처럼 (1)이 붙지 않게, 정확히 `client_secret.json`
4. 파일을 **make-comment 폴더** (CLAUDE.md, README.md가 있는 그 폴더)로 옮겨주세요
   - Windows: 파일 탐색기에서 잘라내기 → make-comment 폴더에 붙여넣기
   - Mac: Finder에서 드래그

## 8단계. 확인

Claude Code에서 **"점검해줘"** 라고 말해보세요.
"자격증명" 항목에 client_secret ○ 가 나오면 성공입니다. 이제 **"인증해줘"** 하면 됩니다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|------|-------------|
| 인증 중 "액세스 차단됨: make-comment에서 잘못된 요청을 전송했습니다" / 403 access_denied | **5단계(테스트 사용자)를 빠뜨린 경우.** 대상 → 테스트 사용자에 본인 이메일 추가 후 다시 "인증해줘" |
| "Google에서 확인하지 않은 앱입니다" 경고 | 정상입니다. 본인이 방금 만든 앱이라서 뜨는 안내입니다. **"고급"** → **"make-comment(안전하지 않음)으로 이동"** 클릭 |
| client_secret.json을 못 찾는다고 나옴 | 파일 이름이 정확히 `client_secret.json`인지, make-comment 폴더 안에 있는지 확인. Windows에서 확장자 숨김이면 `client_secret.json.json`이 됐을 수 있음 |
| 화면 메뉴가 가이드와 다름 | 구글이 화면을 자주 바꿉니다. 위쪽 **검색창**에 "OAuth", "사용자 인증 정보" 등을 검색하면 같은 곳으로 갈 수 있습니다. 막히면 화면을 캡처해 조교에게 보내주세요 |

## 보안 주의 (중요!)

- `client_secret.json`과 (인증 후 생기는) `token.json`은 **내 계정의 열쇠**입니다.
- **절대 남에게 보내거나, 카톡·게시판·화면 캡처에 포함하지 마세요.**
- 컴퓨터를 바꾸면 파일을 옮기지 말고, 새 컴퓨터에서 이 가이드로 다시 발급받는 것이 안전합니다.
